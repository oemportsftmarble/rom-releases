## Overview
**This is where ROM releases will be posted and the reports.**

Do not re-post the download links anywhere else without my permission

## Submitting Reports
**Please follow the steps below**
1.  Go to the **Issues** tab.
2.  Search to ensure the bug hasn't already been reported. Duplicate issues aren't allowed.
3.  Open a new issue using the template provided otherwise I'll close
You have to provide the following:
    *   ROM and Android Version
    *   Current recovery installed
    *   Detailed explanation of the issue with steps to reproduce
    *   Logs (No logs = close ticket)
4.  Wait for a response, it can be me or someone else who knows about the issue. Do not spam as it will only make me close the ticket.
